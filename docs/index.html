The problem · DoorDash’s two challenges

Timing and packing break at peak.

01 · Prep timing

When should this order start cooking?

Orders arrive from different apps with different timing, and pickup times move. Start too early and food sits; too late and the Dasher waits.

How can AI help coordinate prep and timing?

02 · Packing & pickup

Is this bag right, and is it theirs?

Cooked isn’t done. Everything has to be packed right and handed to the right person, and every fix steals time from the next order.

How can AI make pickup more reliable, with less work for staff?

08

Why it works

Built so it can’t quietly be wrong.

The model only looks.

Claude lists what’s in the bag. Matching and the go/hold call are plain code we can read and test.

It can only name menu items.

Its answer is locked to the restaurant’s menu, so it can’t invent a dish that isn’t sold.

About 4 seconds a bag.

3.5–5 s per check in our tests, read from the photo alone. Nobody presses a button.

Service never stalls.

If the model can’t be reached, it reads the codes printed on our cards and bag labels instead.
